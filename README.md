# Streamlit Template

A reusable Streamlit data-app template repo.

## Quickstart

Use the `streamlit-template-setup` skill to bootstrap this repository locally.

Or, to set up manually:

1. Copy `.env.example` to `.env`
2. Run `make setup`
3. Run `make up`
4. Run `make migrate`
5. Run `make seed`
6. Go to http://localhost:8501
